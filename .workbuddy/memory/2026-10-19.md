## 踩坑

- PowerShell 里 `param([string]$Manifest)` 与 `$manifest = ... | ConvertFrom-Json` 是**同一个变量**，`[string]` 类型约束会把解析结果强转成空字符串，表现为“清单 0 条、全部条目被判多余”。脚本内改用 `$manifestData`。

## 修导入/安装进度条不动（13:38）

- 根因：`ensureDownloadProgressListener()` 只在下载链路注册，导入从不经过下载 → Rust 发来的 `game-download-progress` 和 `game-package-scan-progress` 全被丢掉，导入 0%、安装前校验 90% 不动。
- 修复：`importGameChunks` 与 `finalizeGamePackageInstall` 开头各补 `await ensureDownloadProgressListener()`；导入百分比按 `DOWNLOAD_PROGRESS_SHARE`（90）缩放，避免导入跑满 100% 后切到 downloaded 掉回 90%。
- 测试：新增断言“两处都注册监听器 + 百分比按 90 缩放”；`npm test` 256 通过、`npm run build` 通过。

## GitHub 网络提示误报（18:46）

- 现象：幻杀 Github 源下载正跑着（十几 MB/s），右上角仍报"当前未开启网络代理，下载会很慢"。
- 链路：Rust `get_github_network_status` = 查系统代理（注册表 ProxyEnable/ProxyServer）+ 请求一次
  `https://github.com/` 量首字节时间；前端 `githubNetworkWarning` 原来只要 `!proxyDetected` 就断言"会很慢"，
  与 `reachable` / `latencyMs` 无关；探测只在启动/切源跑一次，不是实时速度。
- 修复：
  - `githubNetworkWarning` 只在探测不通或延迟 ≥ 2s 时提示；直连快则不提示，文案改为
    “未检测到网络代理，GitHub 连接不稳定，可在设置里开启代理”；玩家自己关代理时提示“直连较慢，可换回系统代理”。
  - `githubNetworkWarningText` 增加实测速度压制：`downloadTimeEstimator` 10 秒窗口 ≥ 1 MB/s 时横幅/设置页都不提示。
  - 设置页的“代理：… / 延迟 …”保留，只陈述事实。
